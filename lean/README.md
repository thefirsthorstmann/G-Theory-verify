# The Forced spine, machine-checked

This directory is a Lean 4 project. Each file states, in English in its docstrings, a claim
exactly as it appears in a published G-Theory record, and then proves that statement. The
pytest batteries in `../verify` remain the measurement layer: they compute the numbers on
one machine today. These are the proofs: the kernel checks the argument, once, for every
case.

## Build

Requires [elan](https://github.com/leanprover/elan), which installs the pinned Lean
toolchain from `lean-toolchain` on first use.

```
cd lean
lake exe cache get     # downloads Mathlib's prebuilt cache; several gigabytes, once
lake build             # checks every theorem in GTheory/
```

A clean build with no `sorry` and no error is the verification. `lake build` prints
nothing about a theorem that passes; a failing proof is an error with a location.

The Mathlib checkout and the build tree live in `.lake/`, which is a symlink to
`~/.cache/gtheory-lake/.lake` so that gigabytes of dependencies stay out of the repository folder
tree and out of git.

## What is and is not proved

A theorem here proves arithmetic: that an explicit function of the quantum numbers orders
the orbitals as chemistry fills them, that a rational is a perfect square, that a finite
search has one survivor. It does not prove the identification of that arithmetic with a
physical quantity, and no file claims to. Where the record calls something a declared
selection, the docstring says so.
